## 🔒 Política de Privacidad
*Última actualización: Agosto 2026*

* **Datos recabados:** Solo recopilamos los datos estrictamente necesarios para la autenticación mediante la API de Google y Firebase (nombre y dirección de correo electrónico).
* **Uso de imágenes:** ReFrame procesa tus fotografías únicamente con fines de análisis de composición dentro del dispositivo. No almacenamos ni compartimos tus imágenes en servidores externos sin tu consentimiento.
* **Terceros:** La autenticación se gestiona de forma segura a través de Google Cloud Platform y Firebase Authentication.

---

## 📄 Términos y Condiciones de Uso
1. **Uso de la aplicación:** ReFrame se proporciona "tal cual" como herramienta de apoyo fotográfico.
2. **Propiedad intelectual:** Todos los derechos de las imágenes capturadas dentro de la app pertenecen íntegramente al usuario.
3. **Modificaciones:** Nos reservamos el derecho de actualizar la aplicación para introducir mejoras técnicas o de seguridad.
